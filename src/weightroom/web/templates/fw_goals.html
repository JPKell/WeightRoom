Set up a run

Four ways to a goal, in the order most people need them: answer the wizard's questions, fork a starter, hand FreeWeight a pack you wrote, or import a bundle exported from somewhere else. Nothing here writes until you say so.

Define a goal

FreeWeight's wizard: what you are trying to get, then your criteria with two questions asked of each, then the rules that could carry part of them, then your own tasks. Nothing is written until you save.

Create from a pack

A pack written by hand is as first-class as the wizard's: goal.json and the task prompt records. FreeWeight validates and lints it, and a finding never blocks creation.

{{ csrf() }}

Import a bundle

The bundle a goal's page exports — the file freeweight goals export writes. FreeWeight checks its size against goals.max_pack_bytes, every member's path and the bundle's hash before it writes anything, and never overwrites a goal in place.

{{ csrf() }}

Runs

A goal is run from its own page — calibrate the jury there, then run the goal and grade what comes back. What sits here is the wizard's unfinished work, which is FreeWeight's own row and not a file on disk.
