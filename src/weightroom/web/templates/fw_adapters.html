Drafts

A draft is a proposal: FreeWeight and loadcoach adapters scan may both write one, and neither registers anything (ADR-0145). The suffix is what enforces that — nothing reads a .manifest.draft.json as a manifest. Keeping one is renaming it, at a terminal, after a person has read it: mv <name>.manifest.draft.json <name>.manifest.json. Check the base first — a draft records it at name_only confidence with no digest — and set data_classification, which a draft writes as confidential precisely so that a value nobody chose cannot leak anything (ADR-0065).

Without a manifest

A manifest is the reviewed <name>.manifest.json beside an artifact — the file that says what this adapter is: its artifact_sha256, which is its identity, the base it was trained against and how well that is proven, the capabilities it claims, and its data_classification. There is no registry service; the directory and these files are the registry (ADR-0061), and an artifact without one is present and unusable — FreeWeight will not offer it to a provider or measure under it.
